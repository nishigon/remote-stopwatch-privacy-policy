本页面说明 Remote Stopwatch 中用户信息的处理方式。日语版为正式版本。

1. 适用范围

本政策适用于与 Remote Stopwatch 相关而处理的信息。Remote Stopwatch 是一款非官方计时应用，使用两台以上智能手机， 测量起点与终点等分离地点之间的时间。负责 START 和 STOP 的设备加入同一测量房间，应用会校正按下时间并显示结果。 本应用面向训练、练习、活动和娱乐使用，不作为正式比赛计时工具。

2. 不打算收集的信息

初始版本不打算主动收集以下信息：

  • 姓名
  • 电子邮箱地址
  • 位置信息
  • 联系人
  • 照片
  • 音频
  • 设备中的文件
  • 摄像头画面或视频

如果未来新增终点确认视频校正等功能，本政策会在功能发布前更新。

3. 可能取得或处理的信息

  • Room ID、Client ID、joinSecret 以及类似 sessionToken 的临时连接信息
  • 设备角色信息，如 host、starter、stopper、viewer
  • 设备名／赛道名、跑者名等可选标签
  • START 事件、STOP 事件、START／STOP 按下时间
  • elapsedMillis 等测量结果、排名、历史记录
  • RTT、offset、估计误差、WebSocket 连接状态
  • 通信状态、诊断日志、appPhase 等测试日志信息
  • 启用 AdMob 时广告 SDK 处理的广告 ID 等
  • 启用 Google Play Billing 时处理的购买状态

设备名／赛道名、跑者名是用户可选输入的标签，可以使用“1号赛道”“A设备”“终点负责”等通用标签。 如果用户输入个人姓名，该内容可能会显示在同一房间中的其他设备或结果分享文本中。

4. 使用目的

  • 创建、加入和维持测量房间
  • 同步 START／STOP 事件
  • 计算校正后的时间
  • 显示结果、历史记录以及生成复制／分享文本
  • 显示通信状态和估计误差
  • 故障调查和咨询应对
  • 将来引入 Free／Pro 或广告库存控制时用于功能限制判定

5. 保存期间

房间信息和连接信息原则上只在维持测量房间和显示结果所需范围内临时处理。应用内历史记录可能保存在设备中。 如果用户通过 Copy test log 等方式发送日志，该日志可能用于咨询应对和故障调查。

如果未来引入长期云端历史保存，本政策将会更新。

6. 第三方提供、广告与付费

不会出售个人信息。服务器通信可能使用 Cloudflare 等基础设施服务。

如果启用广告，可能使用 Google AdMob，Google 可能会处理广告 ID 等信息。初期测试中，广告可能使用 Mock 或保持禁用。 Free 版可能显示横幅广告或激励广告，Pro 版原则上不显示广告。

如果启用付费，可能使用 Google Play Billing，Google 可能会处理购买状态。未来的 Pro 功能可能包括去广告、无限计时、 多个 STOP 支持以及更强的历史记录保存。开发者不会直接获取支付卡信息。

7. 儿童使用

本应用并非以 13 岁以下儿童为主要对象。未成年人使用本应用时，请由监护人或管理者判断是否适合使用。

8. 安全管理

公开版计划使用 HTTPS／WSS 等安全通信方式。debugLocal 等开发用本地连接不打算用于公开版。签名密钥、秘密信息和令牌不会包含在公开仓库中。

9. 修订

本政策可能根据需要进行修订。最新内容会发布在本页面。
