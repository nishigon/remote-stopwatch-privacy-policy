Remote Stopwatch Privacy Policy deployment

Public URL:
https://nishigon.github.io/remote-stopwatch-privacy-policy/

GitHub Pages setup:
1. Open `nishigon/remote-stopwatch-privacy-policy` on GitHub.
2. Open `Settings`.
3. Open `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select branch `main`.
6. Select folder `/root`.
7. Click `Save`.
8. Wait a few minutes and open `https://nishigon.github.io/remote-stopwatch-privacy-policy/`.

Notes:
- This is a project page, not a folder inside `nishigon.github.io`.
- The repository must be public for GitHub Pages to work as expected.
- Confirm these URLs after deployment:
  - https://nishigon.github.io/remote-stopwatch-privacy-policy/
  - https://nishigon.github.io/remote-stopwatch-privacy-policy/en/
